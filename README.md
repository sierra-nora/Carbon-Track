# CarbonTrack — Student Carbon Footprint Calculator

## Run the website

1. Extract the ZIP.
2. Open `index.html` in any browser.
3. No Node.js or server installation is required.

## Included

- Responsive desktop/mobile layout
- Five-category calculator: food, transport, electricity, waste and consumption
- Working radio-button options and sliders
- Category breakdown chart
- Biggest-contributor identification
- Suggestions and “What if?” scenarios
- Light/dark mode

## Methodology

This website is an educational prototype. The emission factors and calculations are simplified estimates intended for demonstration and awareness purposes and are not intended to provide a scientifically validated carbon footprint assessment.

## Technologies Used

- HTML
